1. Reach the app:
{{- if .Values.ingress.enabled }}
   Ingress:
   {{- range .Values.ingress.hosts }}
     http{{ if $.Values.ingress.tls }}s{{ end }}://{{ .host }}
   {{- end }}
{{- else if .Values.route.enabled }}
   OpenShift Route:
{{- if .Values.route.host }}
     http{{ if .Values.route.tls.enabled }}s{{ end }}://{{ .Values.route.host }}{{ .Values.route.path }}
{{- else }}
     OpenShift generated the hostname. Read it with:

     oc -n {{ .Release.Namespace }} get route {{ include "todo.fullname" . }} -o jsonpath='{.spec.host}'; echo
{{- end }}
{{- else if .Values.httpRoute.enabled }}
   HTTPRoute is attached to your Gateway. Try:
   {{- range .Values.httpRoute.hostnames }}
     https://{{ . }}
   {{- end }}
{{- else }}
   Port-forward (no Ingress/Route/HTTPRoute configured):

     kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "todo.fullname" . }} 8080:{{ .Values.service.port }}
     open http://localhost:8080
{{- end }}

2. Log in (username: {{ .Values.app.auth.username }}):
{{- if .Values.app.auth.existingSecret }}
   Password is in your Secret "{{ .Values.app.auth.existingSecret }}" (key: {{ .Values.app.auth.passwordKey }}).
{{- else if .Values.app.auth.password }}
   Password was taken from values and stored in Secret "{{ include "todo.authSecretName" . }}":

     kubectl -n {{ .Release.Namespace }} get secret {{ include "todo.authSecretName" . }} -o jsonpath='{.data.password}' | base64 -d; echo
{{- else }}
   No password was provided, so the app GENERATED one on first start. Read it from the log:

     kubectl -n {{ .Release.Namespace }} logs deploy/{{ include "todo.fullname" . }} | grep password
{{- end }}

3. Health probes: GET /livez (liveness, never touches the DB) and GET /readyz
   (readiness, pings the DB; /healthz is an alias).

4. Metrics: GET /metrics on the Service port "metrics" ({{ .Values.service.metricsPort }}) — cluster-internal,
   NOT reachable through the Ingress/Route/HTTPRoute. Try:

     kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "todo.fullname" . }} 8081:{{ .Values.service.metricsPort }}
     curl -s http://localhost:8081/metrics | grep -E '^(db_up|todos)'
